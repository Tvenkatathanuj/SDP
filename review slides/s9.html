Speech Module

Tri-Path Architecture

Path 1: CNN on Spectrograms

3-layer Convolutional Neural Network
Input: Mel-spectrograms (128 mel-frequency bins)
Learns temporal-spectral patterns

Path 2: Clinical Features MLP

14 Acoustic Markers:

Pitch (mean, std), Jitter, Shimmer, HNR
Formants (F1, F2, F3), Spectral features
Energy features (RMS mean, std)

Path 3: MFCC Encoder MLP

80 dimensions: 40 MFCC coefficients × 2 (mean + std)
MLP encoder network for feature compression

Fusion: Concatenation + Dense → Speech Embedding
