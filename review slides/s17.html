Caption

The system is deployed as an interactive Flask web application supporting handwriting and speech uploads. It returns a screening-oriented risk label (LOW / MODERATE / HIGH) with CPU-friendly latency (reported < 3 seconds for fusion inference) and a compact footprint when INT8 quantized (~85 MB).

Clinical note: this is a screening tool; confirm diagnosis with professional evaluation.

What the app enables

Simple data capture

Upload spiral/wave images and short speech clips from consumer devices.

Multimodal fusion

CMAFN combines handwriting and speech through cross-attention.

Practical latency

CPU inference reported under 3 seconds for multimodal predictions.

Deployment ready

Quantized packaging reduces size (~85 MB) and supports scalable web deployment.
